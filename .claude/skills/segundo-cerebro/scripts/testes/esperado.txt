# Um caso por linha: pasta | código de saída | rótulos esperados

# Cada caso é a reprodução concreta de um defeito que o lint já teve, e existe
# para impedir que ele volte. Rode com: python3 testes/rodar.py
#
# Dois casos devem ficar LIMPOS (código 0) — são a conferência de falso
# positivo, e falso positivo é o que faz um lint ser ignorado:
#   transitivo-no-sentido-documentado · elo-declarado-so-no-precedente
#
# independente-limpo e independente-sujo vieram de fixtures escritas a partir
# da especificação por quem NÃO viu o código deste script — foi esse par que
# pegou o falso positivo de índice que as fixtures caseiras não pegavam,
# porque as caseiras escreviam o índice no formato que o código já esperava.
# O gabarito delas está em casos/GABARITO-INDEPENDENTE.md.
#
# independente-limpo espera PENDENTE:1 de propósito: a nota tem marcador
# PENDENTE bem usado. O gabarito independente considera que uso correto do
# marcador não deveria virar achado; aqui ele vira, porque a nota de fato
# ainda depende de abrir o acórdão. É divergência de leitura, não defeito —
# e o rótulo é PENDÊNCIA, nunca erro.
